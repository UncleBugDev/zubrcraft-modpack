# ZubrCraft - Сборка модов

Официальный набор модов и конфигов для игры на сервере **ZubrCraft**.

- **Сайт-гайд по установке:** [https://unclebugdev.github.io/zubrcraft-modpack/](https://unclebugdev.github.io/zubrcraft-modpack/)
- **Сервер:** zubrcraft.fun
- **Версия игры:** Minecraft 1.20.1
- **Загрузчик:** Forge 47.3.11 (или новее)
- **Java:** Java 17

---

## Простая установка для игроков
Мы сделали удобный пошаговый онлайн-гайд:  
👉 **[Открыть инструкцию по установке](https://unclebugdev.github.io/zubrcraft-modpack/)**

### Быстрый старт:
1. Скачай **[1_ZubrCraft_Optimization_Base.zip](https://github.com/UncleBugDev/zubrcraft-modpack/releases/latest/download/1_ZubrCraft_Optimization_Base.zip)** из раздела [Releases](https://github.com/UncleBugDev/zubrcraft-modpack/releases).
2. Закинь файлы в папку .minecraft/.
3. Запусти файл Обновить_Сборку.bat (он сам докачает свежие моды сервера).
4. Заходи на сервер zubrcraft.fun с версии **Forge 1.20.1**.

---

## Что внутри
Сборка ориентирована на ламповое выживание и улучшение ванильного геймплея:
- **Голосовой чат:** Simple Voice Chat (настройка микрофона на клавишу V).
- **Контент и декор:** Farmers Delight, Chipped, Handcrafted, Comforts, Supplementaries.
- **Оптимизация и интерфейс:** Embeddium, Oculus (шейдеры), JEI, Jade, ModernFix, FerriteCore, Canary.

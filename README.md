# ZubrCraft - Сборка модов

Официальная сборка модов и конфигов для сервера **ZubrCraft** (Minecraft 1.20.1 Forge).

- **Сайт-гайд по установке:** [https://unclebugdev.github.io/zubrcraft-modpack/](https://unclebugdev.github.io/zubrcraft-modpack/)
- **Основной IP:** `zubrcraft.fun`
- **Резервный IP (для VPN):** `vivo-whomever.tun.ply.gg:43020`
- **Версия игры:** Minecraft 1.20.1 (Forge 47.3.11+)
- **Java:** Java 17

---

## Установка сборки в Prism Launcher / PineconeMC (Рекомендуется)

1. Открой **Prism Launcher** (или PineconeMC).
2. Нажми **«Добавить сборку»** -> вкладка **«Импорт»**.
3. Вставь прямую ссылку на сборку:
   ```
   https://sync.zubrcraft.fun/ZubrCraft-Prism.zip
   ```
   *(Зеркало на GitHub: [ZubrCraft-Prism.zip](https://github.com/UncleBugDev/zubrcraft-modpack/releases/latest/download/ZubrCraft-Prism.zip))*
4. Нажми **ОК**, выдели память (от 3-4 ГБ) и нажми **«Запустить»**.

> **Бесшовное автообновление:** сборка автоматически проверяет и синхронизирует моды с сервером перед каждым запуском. Никаких ручных батников, подтверждений и перезапусков.

## Что внутри
Сборка ориентирована на ламповое выживание и улучшение ванильного геймплея:
- **Голосовой чат:** Simple Voice Chat (настройка микрофона на клавишу `V`).
- **Контент и декор:** Farmers Delight, Miners Delight, Chipped, Handcrafted, Comforts, Supplementaries, Waystones, Tom's Simple Storage, Sophisticated Backpacks.
- **Оптимизация и графика:** Embeddium, Oculus (поддержка шейдеров), ModernFix, FerriteCore, Canary, Saturn, MemoryLeakFix, Noisium.
- **Интерфейс:** JEI (рецепты), Jade (информация о блоках), AppleSkin.
- **Безопасность:** Встроенный ZubrCraft Auth (удобное графическое окно авторизации).

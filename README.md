# ZubrCraft - Сборка модов

Официальный набор модов и конфигов для игры на сервере **ZubrCraft**.

- **Сервер:** `zubrcraft.fun`
- **Версия игры:** Minecraft 1.20.1
- **Загрузчик:** Forge 47.3.11 (или новее)
- **Java:** Java 17

---

## Что внутри
Сборка ориентирована на ламповое выживание и улучшение ванильного геймплея:
- **Голосовой чат:** Simple Voice Chat (настройка микрофона на клавишу V).
- **Контент и декор:** Farmers Delight, Chipped, Handcrafted, Comforts, Supplementaries.
- **Оптимизация и интерфейс:** JEI, Jade, FerriteCore, Canary, Clumps.

---

## Как установить

### Вариант 1. Через обычный лаунчер (TLauncher, Legacy, официальный)
1. Установи версию **Forge 1.20.1**.
2. Скачай архив `ZubrCraft-Client-Latest.zip` из раздела [Releases](https://github.com/UncleBugDev/zubrcraft-modpack/releases).
3. Распакуй содержимое в свою папку игры (`.minecraft/`), заменив файлы при запросе.
4. Запускай игру и подключайся по адресу `zubrcraft.fun`.

### Вариант 2. Через Prism Launcher / Modrinth
1. Скачай файл `zubrcraft.mrpack` из [Releases](https://github.com/UncleBugDev/zubrcraft-modpack/releases).
2. В лаунчере нажми "Добавить инстанс" -> "Импорт из zip/mrpack".
3. Всё скачается само в один клик.

## Если вышло обновление сборки
Зайди во вкладку [Releases](https://github.com/UncleBugDev/zubrcraft-modpack/releases), скачай свежий `ZubrCraft-Update.zip` и закинь папки mods и config в свой `.minecraft` с заменой старых файлов.

# Папка для экспорта чатов с нейросетями

Сюда можно скидывать сохранённые чаты и переписки с AI (в форматах `.txt`, `.md`, `.json`):
- Предыдущие диалоги по разработке и настройке сервера.
- Обсуждения механик и модов.
- Решения ошибок и конфигураций.

Claude Projects автоматически индексирует все текстовые файлы из этой папки и учитывает их при генерации новых модов и кодовой базы!
